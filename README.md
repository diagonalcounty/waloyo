# Waloyo

A chapter game about **humanity growing by generating wealth** — not by winning a war.

The same two people (the settler couple) walk through **historical chapters**. Each chapter is a time, a set of constraints, and a chance to apply principles that create surplus: prices, trade, knowledge, incentives. Then another chapter can be added.

The public name is **Waloyo**. It is not Civilization. It does not ship Firaxis art, audio, or code.

**MVP:** one playable chapter. That is enough to ship.

Product brief: [issue #12](https://github.com/diagonalcounty/waloyo/issues/12).

## What this is not

- Not a Civ IV / Unciv clone or tileset pack.
- Not a game that requires war as the core loop.
- Not a host for Firaxis binaries or ripped Civ art.
